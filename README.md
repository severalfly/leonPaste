# leonPaste

一个受 macOS [Paste](https://pasteapp.io/) 启发的**剪贴板历史管理器**，为 Windows 10 / 11 设计。

复制过的文字不再消失：后台自动记录、随时用全局热键唤起悬浮面板，搜索、收藏、一键写回剪贴板。
数据全部存在本地，不联网、不上传、无账号。

## 功能

- **自动记录**：后台线程（180ms）与**前端主线程定时同步（500ms）**双路径读取，共享内容签名去重；已验证主线程能稳定读到剪贴板，即使后台线程受限也能记录。**文本优先**，图片 / 文件列表同样支持
- **智能分类**：文本 / 链接 / 代码 / 颜色 / 路径，可一键筛选
- **底部横条**：无边框置顶窗口**按当前屏幕自适应**并横向铺满左右，256–336px 大卡片、毛玻璃、错落入场动画与选中放大，每项都有真实预览；主窗口只保留搜索框与卡片流，过滤条/状态栏/快捷键提示等全部可收纳进设置
- **横向滑动**：滚轮、拖拽、方向键、两端箭头均可浏览；点击卡片或 `Enter` 即写回剪贴板
- **失焦收起**：点击其他应用以淡出动画收起到**托盘**（**不会退出进程**），等同 `Esc`；设置里可关闭，托盘右键能看到运行状态
- **首次启动可见**：第一次运行自动弹出一次面板，避免「双击后什么都没有」
- **全局热键**：默认 `Alt+Shift+V`，设置里可**录制任意组合键**（Ctrl/Alt/Shift + 字母、数字、F1–F12、空格等），也可手动输入
- **即时搜索**：输入即过滤（筛选在前端完成，列表数据走无参数命令，不再受参数名映射影响），`←` `→` 选择，`Enter` 写回剪贴板，`Esc` 关闭
- **图片与文件**：位图生成缩略图预览并原样写回；复制的文件列表也能被记录
- **关于与诊断**：设置页显示版本号、开发者、许可证、仓库、构建目标、数据目录、已记录条数、监听心跳、读取计数与最近日志；「检测剪贴板」按钮 + 一键打开数据目录。**空列表时直接显示监听状态与计数，并提供「清除筛选 / 检测剪贴板」按钮**
- **自动粘贴**：选中后可模拟 `Ctrl+V` 直接粘到当前应用（可关）
- **收藏与清理**：收藏置顶、单条删除、清空历史（保留收藏）
- **系统托盘**：显示 / 隐藏、暂停记录、清空、退出
- **设置**：容量上限、保留天数、深浅主题、忽略关键词、开机自启、暂停记录
- **便携模式**：数据写在 exe 同目录 `data/`，不写注册表、不写 `%APPDATA%`
- **单实例**、无边框置顶窗口、纯本地 JSON 存储

## 安装与使用

从 [Releases](https://github.com/severalfly/leonPaste/releases) 下载最新版 `leonPaste-<版本>-portable.zip`，
解压到任意目录，双击 `leonPaste.exe` 即可。

- **Windows 11**：WebView2 运行时已内置，开箱即用。
- **Windows 10 (1803+)**：若未安装 WebView2 Evergreen Runtime，首次启动会提示下载；
  也可从微软官网手动安装。
- 请勿删除同目录的 `WebView2Loader.dll`。
- `portable.dat` 存在即便携模式；删掉它则改为标准模式（配置写入 `%APPDATA%`）。

## 技术栈

| 层 | 选型 |
|---|---|
| 外壳 | Tauri 2（Rust） |
| 界面 | Vue 3 + TypeScript + Vite |
| 剪贴板 | `clipboard-win`（Win32 Clipboard API） |
| 全局热键 / 自启 / 单实例 | Tauri 官方插件 |
| 存储 | 本地 JSON（`history.json` / `settings.json`） |

目标是单个约 10 MB 的 exe，不依赖 .NET、不装 Visual Studio。



## 0.3.0 界面说明

主窗口默认只显示搜索框和横向卡片流。过滤条、状态栏与快捷键提示默认隐藏，可在「设置 → 界面」里分别打开；默认过滤类型也可在设置里指定。点击其他应用时窗口会淡出收起到托盘（进程继续运行），按 `Alt+Shift+V` 再次唤起；若不想自动收起，在「设置 → 界面」关闭该开关。

## 0.3.1 显示与滚动

主窗口不再写死 1440×430：每次唤起都按**鼠标所在显示器**的逻辑像素重算尺寸，宽度占满左右，高度随屏幕比例在 340–520 CSS px 之间取值，再乘该屏幕的 `scale_factor` 换算成物理像素并重新定位到屏幕下方。因此 100% / 125% / 150% 缩放、外接显示器与笔记本屏之间切换，布局比例保持一致，不会超屏或错位；多显示器与拔掉外接屏的场景也自动适配。卡片宽度随窗口在 256–336px 之间自适应。鼠标滚轮与触控板可连续横向滚动（已移除会把滚动「吸回去」的 `scroll-snap` 吸附）。

## 0.3.2 托盘守护与尺寸回调

**托盘偶发消失**这次做了完整兜底。审读全部 Rust 源码后，把可能的退出路径逐条堵上：全局 panic hook 会把任何线程的崩溃（含消息与文件行号）写进 `data\leonpaste.log`；所有 `Mutex::lock().unwrap()` 改为 poison 容错，避免一个线程崩溃拖垮整个进程；剪贴板文本改为按 `GlobalSize` 一次性建切片（不再逐字符找 NUL）并限制文本 16MB / 位图 32MB；`sync_clipboard`、探测命令与后台监听线程都用 `catch_unwind` 包裹；拦截 `CloseRequested`（改为隐藏窗口）以及所有非托盘菜单触发的 `ExitRequested`（`prevent_exit`），窗口被意外销毁也不会退出。托盘显式命名为 `main`，每次唤起刷新图标，每分钟心跳检测，对象丢失则自动重建整套托盘与菜单。

日志现在每分钟写一条 `alive #N tick=... entries=...`，事件循环正常结束写 `exit: event loop ended`。**下次若再遇到图标消失，把 `data\leonpaste.log` 最后 30 行发出来**即可直接区分：日志戛然而止（硬崩溃）/ 有 `PANIC` 行（Rust 崩溃点）/ 有 `exit: blocked unexpected ExitRequested`（被误要求退出，已被拦住）/ 心跳一直持续（进程仍在，只是通知区域图标被系统清理）。

**尺寸回调**：按反馈把单个候选框整体缩小约 20%（卡片 `clamp(256px, 20vw, 336px)`，内边距、字号、预览行数、图标、搜索框回到 0.3.0 的紧凑尺寸），窗口高度从 340–520 回调到 320–440（大屏约 440，接近 0.3.0 的 430）。横向铺满左右与跨屏 DPI 自适应保持不变。

## 0.3.3 鼠标点击粘贴

「选中后回车能粘贴，鼠标单击 / 双击都不行」的根因在 `onPointerDown` 里对 `.track` 调用了 `setPointerCapture`：指针捕获会把 `pointerup` 重定向到 `.track`，浏览器随后把 `click` 派发给 `pointerdown` 与 `pointerup` 目标的**最近公共祖先**（同样是 `.track`），卡片上的 `@click` 因此永远收不到；键盘 `Enter` 走独立逻辑，所以一直正常。

现在移除指针捕获，改用 window 级 `pointermove` / `pointerup` / `pointercancel` 监听（拖出卡片照样能横向滚动）；粘贴由 `pointerup` 主触发，要求按下与松开在同一张卡片且位移不超过 6px 死区，`click` 作为 400ms 去重后的兜底；双击按同卡片 250ms 去重，只粘贴一次。`.star` 收藏按钮仍由 `@click.stop` 独立处理，组件卸载会移除 window 级监听。

## 0.3.4 托盘退出：日志取证与自愈

用户提供 `leonpaste.log` 后按北京时间对齐：13:44:12、14:12:14 两次 0.3.1 启动，14:49:28 一次 0.3.2+ 启动（含 `heartbeat-started`）。**全程没有 `PANIC`、没有 `exit: event loop ended`、没有 `quit: tray menu`、没有 `exit: blocked unexpected ExitRequested`** —— Rust 层的所有退出防护都没被触发；中间那次实例持续捕获约 37 分钟，也不是启动即崩。0.3.2 心跳为 60 秒一次，而最后一次启动到日志快照只有 21 秒，所以「缺少 `alive` 行」既不能单独证明进程已死，也不能排除被硬终止。

因此这次补的是**更底层**的能力：SEH 未处理异常过滤（`SetUnhandledExceptionFilter`）把 native 异常码写进日志，例如 `SEH_EXCEPTION code=0xC0000005`；`RegisterApplicationRestart` 让 Windows 在崩溃后尝试自动拉起；心跳缩到 20 秒并带 `tray=` 状态，每 60 秒在**主线程**无条件删除并重建整个托盘（旧版心跳只检测、不刷新，图标被系统清理后要等按热键才恢复）；`setup-start vX.Y.Z pid=...`、热键、`show: begin/done`、`hide`、`toggle`、`tray-periodic-rebuild` 全部留痕，能看到异常前最后一步。

**下次再遇到时，请先确认一件事**：图标消失的瞬间按 `Alt+Shift+V`，面板还能不能弹出来？能弹出 = 进程还在，只是通知区域图标被系统清理（0.3.4 会自动重建）；弹不出 = 进程确实终止（日志里应出现 `SEH_EXCEPTION`，把最后 30 行发来即可看到异常码）。

## 0.3.5 显示器切换（稳定复现的场景）

「切换外接显示器 ↔ 笔记本屏时自动退出，稳定复现」是最关键的线索。Windows 会在显示器拓扑 / DPI 变化时重建任务栏通知区域，常驻托盘图标会被清掉；WebView2 跨 DPI 显示器也容易出问题。0.3.4 只在每 60 秒固定重建一次托盘，切换后要等很久才恢复，看起来就像「退出」。

现在心跳 **5 秒**一次，实时计算显示器指纹（数量 / 分辨率 / 缩放 / 位置）；一旦变化立即写 `display-topology-changed: <旧> -> <新>`，并在累计 **1s / 3s / 8s / 15s** 分四次重建托盘图标与菜单，覆盖 explorer 重建通知区域的时间窗（带防重入，避免来回切换时并发重建）。**切屏期间不触碰窗口**，`fit_window` 只在用户唤起面板时执行，避免在 DPI 切换过程中 resize WebView2 窗口。启动时写 `display-topology: <指纹>`，`alive` 每 20 秒一条并带 `mon=<指纹>`；固定 60 秒的无条件重建保留作兜底。

升级后如果切屏仍会「退出」，请把日志发我：看 `display-topology-changed` 之后是否还有 `alive`（有＝进程还在、只是图标问题），或者直接出现 `SEH_EXCEPTION`（进程崩溃，异常码可定位）。

## 0.3.6 设置页布局与失焦

- **设置页太宽**：主窗口横向铺满屏幕后，设置抽屉也跟着铺满，字段的 `space-between` 把标签和控件拉到屏幕两端，中间一大片空白。现在把抽屉的头部 / 主体 / 底部统一限宽 **760px 并居中**，字段改为左对齐、标签固定 210px 宽，控件紧跟标签；抽屉圆角与外层统一为 20px。背景仍铺满，不会露出后面的卡片流。
- **设置页失焦不隐藏**：`onBlur` 原先带 `!showSettings` 例外，导致打开设置时点击别的应用不会收起。现在去掉该例外，设置页与主界面一致，失焦即淡出收起到托盘；唤起时顺带重置热键「录制」状态，避免残留。

## 权限与排查

leonPaste 是 Win32 桌面程序，读取剪贴板**不需要**管理员权限，也不需要 Windows「隐私 → 剪贴板」里的任何开关（那些只管 UWP 应用、剪贴板历史与云同步）。Win11 自带 WebView2；Win10 首次启动会提示安装运行时。

若「复制后列表为空」，按顺序检查：

0. **先看空列表上的提示**：若显示「列表加载失败」，界面会直接打印错误详情；若显示「有 N 条记录，当前条件下没有匹配项」，点「清除筛选」。
1. **设置 → 关于与诊断 → 版本号**：确认是最新版。程序单实例且常驻后台，升级前必须先退出旧进程（托盘右键「退出 leonPaste」，或 `taskkill /f /im leonPaste.exe`），否则双击新 exe 会把请求交给旧进程。
2. **点「检测剪贴板」**：复制一段文字后点它。
   - 显示 `text` 加内容 → 程序能读到剪贴板；
   - 显示 `busy` → 剪贴板被其他程序长期占用（安全软件 / 企业 DLP / 其它剪贴板管理器）；
   - 显示 `empty` → 复制发生在另一个会话（RDP、远程桌面、不同用户），剪贴板按会话隔离。
3. **看读取计数**：`循环 / 成功读取 / 被占用 / 捕获`。循环与成功读取在涨说明监听活着；捕获不涨说明内容签名没变。
4. **看最近日志**：`captured` 表示捕获成功，`skip: ...` 会给出跳过原因。
5. **数据目录**：点「打开目录」查看 `history.json`、`settings.json`、`leonpaste.log`；若目录不可写，把整个文件夹移到桌面或用户目录再运行。

常见拦截来源：第三方安全软件、企业 DLP、远程桌面剪贴板重定向，以及以不同用户 / 管理员身份运行的程序。

## 本地开发

Windows 上需要：Node.js 18+、Rust（`stable-x86_64-pc-windows-gnu`）、
MSYS2 mingw-w64（`mingw-w64-x86_64-gcc` + `binutils`），并把 `C:/msys64/mingw64/bin` 加入 PATH。
`.cargo/config.toml` 已配好 GNU linker；若 MSYS2 不在默认路径，可用环境变量
`CARGO_TARGET_X86_64_PC_WINDOWS_GNU_LINKER` 覆盖。

```bat
npm install
npm run dev                    :: 仅前端调试
npm run build                  :: vue-tsc 类型检查 + vite 构建
npm run tauri:build            :: tauri build --no-bundle --target x86_64-pc-windows-gnu
npm run portable               :: 生成 dist-portable 便携目录
```

`tauri build` 的 `beforeBuildCommand` 会自动执行前端构建。
